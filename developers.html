DEVELOPERS

开发者 API

以稳定契约的 JSON API 获取 CreditsPlan 人工核对的 AI Coding 套餐价格、额度与价格历史数据。数据与站点展示同源，每条记录带官方来源链接与最近核对日期。

端点

GET /api/v1/plans.json
全部已核对套餐：价格（月/季/年/首月）、币种、额度、权益、退款政策、购买状态、官方来源与核对日期。
GET /api/v1/price-history.json
按套餐归档的月费价格历史（日期 + 价格记录点），适合做价格走势与变动监控。
GET /api/v1/meta.json
数据集元信息：schema 版本、生成时间与条目数量。

鉴权与调用

所有端点需要在请求头携带 X-API-Key；缺失或无效返回 401。

curl -H "X-API-Key: cpk_你的密钥" \
  https://www.creditsplan.cn/api/v1/plans.json
  • 响应为 UTF-8 JSON，顶层含 schema_version 与 generated_at。
  • 契约承诺：v1 字段只增不改名、不删除；破坏性变更会以 v2 新版本发布。
  • 限速：每密钥 5 请求/秒；响应缓存 5 分钟。数据随站点发布更新（通常每个工作日）。

字段说明（plans.json 摘要）

plan_id
— 稳定套餐标识（品牌 slug + 套餐 slug），跨版本不变。
monthly_price / quarterly_price / yearly_price
— 各计费周期刊例价，币种见 monthly_currency；null 表示官方未公开。
included_calls / token_limit / credits_limit
— 官方页原文记录的额度说明，不做推算。
last_verified_at / data_status / source_url
— 最近人工核对日期、核对状态与官方来源页链接。

使用条款要点

  • 数据可用于产品与研究，转载展示时请注明来源 CreditsPlan 并保留核对日期。
  • 禁止转售原始数据集或将密钥共享给第三方。
  • 价格快照仅供参考，交易请以厂商官网实时价格为准。
