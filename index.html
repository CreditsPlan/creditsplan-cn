国内 Coding Plan 支持 Claude Code 吗？

5 小时限额是什么意思？
指任意连续 5 小时窗口内的最大可用额度，用于衡量突发使用能力；它不等于每日上限，也不能线性折算到周/月额度。各平台计量口径不同（Token/积分/请求次数），跨平台比较时应先对齐计费单位。
套餐价格多久核对一次？
CreditsPlan 通过自动采集加人工审核持续跟踪官方定价页，每条记录标注最近核对日期；历史调价记录见价格变动时间线。
首月优惠价划算吗？
首月/首购优惠价适合短期体验，长期订阅应以续费价（标准月价）为准。本站套餐表同时展示标准月价与首月价，便于对比。
